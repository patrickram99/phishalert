# 07 — Demo al 100 % (Evidencia 4) — PENDIENTE

## Objetivo

Llevar la demo de "funciona de extremo a extremo" a "lista para presentar": modelo final, explicaciones más ricas y arranque sin reentrenar.

## Requisitos

### Modelo final

- **R1** Entrenamiento completo: todo `train`, 3 épocas, selección del mejor checkpoint por F1 de validación.
- **R2** Modelo publicado en Hugging Face Hub (`<usuario>/phishalert-distilbert-multilingual`) con tarjeta de modelo (datos, métricas, limitaciones). `PhishClassifier` acepta tanto una ruta local como un identificador del Hub.
- **R3** La app y la notebook de demo cargan el modelo publicado: la demo arranca en menos de 2 minutos sin reentrenar.

### Riesgo de enlaces (`url_risk.py`)

- **R4** `assess_url(url, orgs_mencionadas)` devuelve `{"risk": "alto"|"medio"|"bajo", "reasons": [...]}`.
- **R5** Señales: host es una dirección IP; acortador conocido (`bit.ly`, `tinyurl.com`, `t.co`…); TLD de alto abuso (`.xyz`, `.top`, `.click`…); `http` sin TLS; subdominios excesivos (≥4 niveles); caracteres `@` o punycode (`xn--`) en el host; **el mensaje menciona una organización cuyo dominio oficial no coincide con el del enlace** (tabla `marca → dominios oficiales`).
- **R6** La tabla de entidades de la app agrega la columna **Riesgo** con el motivo.

### Explicación basada en el modelo

- **R7** `explain(texto)` calcula la importancia de cada palabra por oclusión (probabilidad con la palabra enmascarada vs. original) y devuelve las 5 palabras que más aportan a la clase phishing.
- **R8** La app muestra dos vistas: "Patrones conocidos" (léxico, spec 03) y "Lo que pesó en el modelo" (R7).

### Robustez y experiencia

- **R9** Textos largos: se analizan por ventanas de 256 tokens con solape y se toma la probabilidad máxima; no se trunca en silencio.
- **R10** Umbral de decisión configurable (control deslizante, por defecto 0.5) con tres niveles de veredicto: seguro / sospechoso / phishing.
- **R11** Detección de idioma (`langdetect` o heurística) mostrada en el resumen; advertencia si no es ES ni EN.
- **R12** Ningún texto analizado se guarda en disco ni se registra en logs.

## Criterios de aceptación

- [ ] Notebook de demo: de runtime limpio a enlace público en < 2 min.
- [ ] Un mensaje que menciona "BCP" con enlace a `bcp-seguro.xyz` aparece con riesgo **alto** y motivo de dominio no oficial.
- [ ] Un correo de 3000 palabras se analiza sin error.
- [ ] Las pruebas de la spec 06 R8 cubren R4–R5.

## Cómo ejecutar esta spec

```bash
python scripts/train.py --epochs 3 --max-train 0 --select-best --out models/phishalert
huggingface-cli login
python scripts/publish.py --model models/phishalert --repo <usuario>/phishalert-distilbert-multilingual
python app.py --model <usuario>/phishalert-distilbert-multilingual --share
```

Archivos a crear: `src/phishalert/url_risk.py`, `src/phishalert/explain.py`, `scripts/publish.py`, `notebooks/PhishAlert_demo.ipynb`. A modificar: `train.py` (`--select-best`), `classifier.py` (ventanas, Hub), `pipeline.py`, `app.py`.
